Screen automation with safe stops

The demo CRM has no API, so the robot works from screenshots. Before each action it reads the screen with OCR and confirms the app, the screen, and that this is the demo environment. If any of that is off, it stops and sends nothing.

Extraction with hard checks

Statements captured from the screen become structured data. Then plain code recomputes every line and total. It never corrects a figure: a statement passes everything or goes to a person.

Reviewed notes

Transcripts imported from Microsoft Teams and Granola formats become draft notes. Nothing reaches the CRM until a named person approves it, and then the robot types it, reads it back and saves it.
